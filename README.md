# 元素作图工作台 V2

元素作图工作台是一个在浏览器本地运行的地球化学数据作图工具。它可以读取 Excel 或 CSV 表格，绘制散点图和元素配分折线图，并导出 PNG、SVG 或保存到本地历史记录。

导入的数据只在当前浏览器中处理，不会上传到服务器。

## 打开工作台

1. 双击打开 `index.html`。
2. 进入“数据”页并选择 Excel 或 CSV 文件。
3. 数据读取完成后，进入“作图工作台”。

Excel 文件依赖页面加载 SheetJS。如果电脑无法联网且 Excel 文件不能读取，可以先把数据另存为 CSV 后导入。

## 准备数据

工作台支持：

- `.xlsx`
- `.xls`
- `.csv`

建议数据表遵循以下规则：

- 每一列有明确的列名。
- 每一行代表一个样品或一条记录。
- 元素含量列使用纯数值，空缺值留空。
- 分类信息放在单独的列中，例如 `Type`、`Mission`、`Sub`。
- 样品名称可使用 `Sample ID`、`Sample` 或 `Name`。
- 记录编号可使用 `Record_ID`、`RecordID` 或 `Record ID`。

如果表格中出现重复列名，工作台会自动重命名。例如第二个 `Cr_ppm` 会显示为 `Cr_ppm_2`。

## 数据页

### 导入文件

点击“选择 Excel / CSV 文件”并选择数据文件。导入完成后，页面会显示：

- 数据行数
- 列数
- 识别出的数值列数量
- 前 200 行数据预览

Excel 文件包含多个 Sheet 时，可以通过 Sheet 下拉框切换。

### 创建比值列

1. 选择分子列。
2. 选择分母列。
3. 输入新列名，例如 `La/Yb`。
4. 点击“生成比值列”。

新列会立即加入数值字段列表。“已创建计算列”会记录公式来源。点击对应的“删除”可以移除计算列，相关坐标轴或元素组合中的失效引用也会同步清理。

## 作图工作台

左右两栏按功能分成多个区域。点击区域标题可以折叠或展开。左右栏边缘的拖动条可用于调整栏宽。

### 绘制散点图

1. 在“图形与字段”中选择“散点图”。
2. 选择 X 轴字段和 Y 轴字段。
3. 在“分类与筛选”中选择分类字段和需要显示的分类。
4. 根据需要设置坐标轴、趋势线和图例。

把鼠标移到数据点附近，可以查看样品名称、`Record_ID`、X/Y 数值和分类。

### 绘制元素配分折线图

1. 在“图形与字段”中选择“元素配分折线图”。
2. 展开“元素序列与平均方式”。
3. 勾选至少两个元素列。
4. 使用 `↑`、`↓` 调整元素顺序。
5. 选择线条模式。

可用模式：

- 每个样品一条线
- 按当前分类平均
- 按指定字段平均

平均线可以显示数据点和 ±1 SD 阴影。元素名称较多时，横坐标标签会根据可用空间自动倾斜并调整底部留白。

### 元素组合

选择元素并调整顺序后，可以输入组合名称并点击“保存”。之后可以从下拉框中载入或删除组合。

已经保存的组合可以在不同浏览器或不同版本之间交换：

- 点击“导出组合”，把当前保存的全部组合下载为 `element-sets.json`。
- 点击“导入组合”，选择一个元素组合 JSON。
- 导入文件可以同时包含多个组合。
- 同名组合会使用导入文件中的内容更新。
- 当前数据缺少某些元素时，这些名称仍会保存在组合中；载入时只勾选当前数据实际存在的列。

快捷预设包括：

- 稀土序列
- 所有以 `_N` 结尾的标准化列

## 分类与筛选

“当前分类字段”决定样品按什么信息分组，例如 `Type` 或 `Mission`。

分类列表提供：

- 全选
- 全不选
- 反选

取消某个分类后，该分类的数据不会出现在当前图件中。

## 样品集合

样品集合用于从当前筛选结果中建立自定义分组。例如，可以从 Apollo 14 样品中单独建立一个 `Apollo 14 KREEP` 集合。

1. 先通过分类列表筛选出目标样品。
2. 输入集合名称。
3. 点击“创建当前筛选集合”。

三种集合优先级：

- 仅当前分类字段：不使用集合覆盖分类。
- 集合覆盖原分类：集合中的样品使用集合名称，其他样品仍使用原分类。
- 原分类 + 样品集合：显示为“原分类 / 集合名称”。

点击样品集合旁的“删除”可以移除该集合，不会删除原始数据。

## 图表标题与坐标轴

可以设置：

- 图表标题
- X/Y 轴标题
- X/Y 最小值和最大值
- 主刻度间距
- 对数坐标
- 反向坐标
- 细分刻度

设置后点击“应用坐标轴”。

标题输入框为空时，图中不会自动显示字段名。需要标题时请直接输入希望显示的文字。

在线性坐标中，即使坐标范围没有正好落在主刻度间距上，细分刻度也会覆盖完整的坐标范围。对数坐标的细分刻度按每个数量级的 2–9 绘制。

## 趋势线

趋势线只在散点图中显示。

1. 展开“趋势线”。
2. 勾选“显示分组趋势线”。
3. 选择拟合方式。
4. 设置默认线宽和透明度。

每个分类可以单独设置：

- 是否显示
- 线型
- 是否继承图例颜色
- 自定义颜色
- 线宽
- 透明度

## 图例样式和取色器

展开“图例样式”，选择一个分类项进行编辑。

可设置：

- 填充色
- 边框色
- 点形状
- 线型
- 线宽
- 透明度

点击颜色方块可以打开系统取色器，也可以在旁边输入准确的 HEX 颜色值。取色过程中只更新小型预览；点击“应用样式”后才会重绘整张图。

图例还支持：

- 导入图例设置 JSON
- 导出图例设置 JSON
- 应用内置参考图例
- 调整点大小
- 调整图例缩放
- 在图中拖动图例位置

## 配置文件归档目录

工作台版本目录中提供两个配置归档文件夹：

- `legend-styles/`：存放图例样式 JSON、示例和说明。
- `element-sets/`：存放元素组合 JSON、示例和说明。

普通静态网页不能在没有授权的情况下直接写入工作台目录。点击导出后，浏览器会把 JSON 保存到下载位置或打开保存对话框。需要长期归档时，请把下载的文件复制到对应目录。

归档目录中的 JSON 和浏览器本地保存互不替代：

- 浏览器本地保存便于当前工作台快速载入。
- JSON 归档便于备份、改名、复制和跨版本使用。

## 导出

### PNG

导出当前高清图件，包括图例。

### SVG

导出可编辑的矢量图。标题、坐标轴、刻度、数据系列、趋势线、SD 阴影和图例会尽量使用独立分组，便于在 Adobe Illustrator 中继续编辑。

## 历史记录

点击“保存当前图件”后，图件会保存在当前浏览器的历史记录中。

历史预览支持数据点悬停提示。保存历史图件不会改变当前作图状态。

历史记录使用浏览器本地存储。空间不足时，工作台会优先清理较早的记录。清理浏览器网站数据会同时删除历史记录、已保存元素组合和图例样式。

## 常见问题

### Excel 文件无法读取

Excel 解析库可能没有加载。检查网络连接，或者把文件另存为 CSV 后重新导入。

### 某些点没有画出来

可能原因：

- 对应分类没有被勾选。
- X/Y 单元格为空或不是数值。
- 数据超出手动坐标范围。
- 对数坐标下的数据小于或等于 0。
- 选择了自动重命名后的另一个重复列。

### 图中没有标题

V2 不会自动使用字段名作为标题。请在“图表标题与坐标轴”中输入标题并点击“应用坐标轴”。

### 图例 JSON 导入后没有变化

图例设置按分类名称匹配。分类名称需要和当前图例中的名称一致。匹配会忽略大小写、首尾空格以及部分长短横线差异，但不会推测完全不同的名称。

### 取色时图件为什么没有立即变化

这是为了避免连续取色导致整张高清图反复重绘。取色器旁的小图标会先显示草稿效果，点击“应用样式”后图件才会更新。

## 数据安全

- 数据只在浏览器本地处理。
- 工作台不会主动上传数据。
- 导出的文件由浏览器保存到下载目录。
- 关闭页面后，当前导入的数据和未保存的样品集合不会保留。
