# 新版元素作图工作台

本项目是一个本地静态网页工作台，用于导入 Excel/CSV 数据并绘制地球化学散点图和元素配分折线图。数据只在浏览器本地处理，不上传服务器。

## 快速开始

1. 打开 `index.html`。
2. 在“数据”页导入 `.xlsx`、`.xls` 或 `.csv` 文件。
3. 在“作图工作台”页选择图类型、X/Y 字段或元素序列。
4. 设置分类字段、筛选分类项、调整图例样式。
5. 导出 PNG/SVG，或保存当前图件到历史记录。

> Excel 导入依赖浏览器加载 SheetJS。如果离线环境无法加载在线脚本，可先使用 CSV，或将 SheetJS 浏览器包放到本地后修改 `index.html` 引用。

## 数据导入

- 支持 Excel/CSV。
- 自动识别列名和数值列。
- 重复列名会自动改名，例如第二个 `Cr_ppm` 会成为 `Cr_ppm_2`，避免覆盖原始列。
- 支持新增比值列：选择分子列、分母列并输入新列名。
- 新增的比值列会进入“已创建计算列”，可查看公式来源并删除。删除后会同步清理 X/Y 轴、元素组合和数据预览中的失效引用。

## 散点图

- 自由选择 X/Y 轴字段。
- 支持坐标轴标题、范围、主刻度、对数坐标、反向坐标和细分刻度。
- 对数坐标开启“显示细分刻度”后，会绘制每个数量级内的 2-9 细分刻度，导出的 SVG 也保持一致。
- 支持按当前分类分别绘制趋势线。趋势线颜色和线型继承图例项，可统一调整线宽和透明度。
- 趋势线可按分类单独控制显示/隐藏，并可分别设置线型、颜色、线宽和透明度。线型包括实线、虚线、点线和点划线；颜色留空时继承对应图例颜色。
- Tooltip 显示样品、`Record_ID`、X/Y 值和分类。
- 大量散点使用 Canvas 绘制，避免 SVG 节点过多导致卡顿。

## 元素配分折线图

- 可任意选择元素列。
- 元素顺序可通过列表中的 `↑` / `↓` 调整。
- 支持保存、载入和删除元素组合。
- 支持稀土元素序列和所有 `_N` 标准化列预设。
- 支持三种线条模式：
  - 每个样品一条线
  - 按当前分类字段平均
  - 按指定字段平均
- 平均线可显示 ±1 SD 阴影。

## 分类、筛选和样品集合

- 当前分类字段支持 `Type`、`Ti`、`Ti_Type`、`Mission`、`Sub`、`Sub_Type`、`Parent_Sample_ID` 等字段。
- 筛选按钮：
  - `全选`
  - `全不选`
  - `反选`
- 可以把当前筛选得到的样品保存为样品集合。
- 已创建样品集合可在列表中删除。
- 样品集合优先级：
  - `仅当前分类字段`：按原始分类字段分组。
  - `集合覆盖原分类`：命中样品集合的样品显示集合名，未命中者仍按原分类字段。此模式下筛选列表会同时出现集合项和原始分类项，且同一样品不会重复绘制。
  - `原分类 + 样品集合`：命中集合的样品显示为 `原分类 / 集合名`。

## 图例样式

每个分类项支持：

- 填充色 HEX
- 边框色 HEX
- 点形状
- 线型
- 线宽
- 透明度

为避免浏览器原生取色器卡顿，当前版本不使用拖动式取色器，而使用 HEX 输入和预设色板。

## 图例设置导入/导出

- `导出图例设置`：导出当前分类项样式为 `legend-styles.json`。
- `导入图例设置`：导入 JSON 并按分类名称匹配应用。
- `应用参考图例`：应用内置月球样品图例参考配置。

JSON 格式示例：

```json
{
  "version": 1,
  "name": "Legend styles",
  "styles": {
    "CE-6 Low-Ti": {
      "fill": "#8f3fb5",
      "stroke": "#ff00ff",
      "shape": "square",
      "lineType": "solid",
      "lineWidth": 3,
      "opacity": 1
    }
  }
}
```

## 历史记录

- 点击“保存当前图件”会追加历史记录，不覆盖旧记录。
- 历史记录保存轻量图片预览和点位 tooltip 信息。
- 新保存的历史图件在预览中悬停可查看数据点信息。

## 导出

- PNG：导出当前图件的高清 Canvas 合成图。
- SVG：按标题、坐标轴、刻度、数据组和图例组分组，便于 Adobe Illustrator 编辑。

## 常见问题

### 为什么某些点没有画出来？

常见原因：

- 当前分类筛选未选中该类别。
- X/Y 字段不是数值或为空。
- 点超出手动设置的坐标范围。
- 对数坐标下数据小于或等于 0。
- 重复表头导致选错列，例如 `Cr_ppm` 和 `Cr_ppm_2`。

### 为什么图例 JSON 导入后没有变化？

导入按分类名称匹配。请确认 JSON 中分类名和当前分类字段生成的图例项一致。名称匹配会忽略大小写、首尾空格和部分长短横线差异，但不会自动理解完全不同的命名体系。

### 如何上传到 GitHub？

可以直接上传整个 `Element-Plot-Workbench-New` 文件夹，或上传压缩包解压后的内容。若作为 GitHub Pages 使用，仓库根目录保留 `index.html` 即可。
